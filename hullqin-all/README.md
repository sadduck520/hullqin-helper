# HullQin 游戏助手（整合版）

一个油猴脚本集成五个游戏助手：**🐘 斗兽棋 / ♞ 国际象棋 / ⚫ 五子棋 / 🃏 斗地主 / 🎯 跳棋**。
安装 `HullQin游戏助手.user.js` 一个文件即可，进入对应游戏页面时面板自动出现并切换到该游戏的控制界面；离开五个游戏后面板自动隐藏。

## 与独立版的关系

功能完全一致，二选一安装即可：

| 游戏 | 路由 | 特性 |
|---|---|---|
| 斗兽棋 | /dsq | 提示 / 自动代走（进入页面且**开始游戏后**才显示面板） |
| 国际象棋 | /gjxq | Stockfish / 自研双引擎、1-10 难度、评估条 |
| 五子棋 | /wzq | 8 种规则全支持（含禁手）、思考深度 1-10 层 |
| 斗地主 | /ddz | 记牌器 / 出牌提示 / 托管（自动叫抢地主+出牌） |
| 跳棋 | /tq | 2-6 人全布局、💡提示 / 托管、本地对战可选代走方 |

## 构建

```bash
node build.js     # 产出 HullQin游戏助手.user.js（依赖 ../hullqin-shared 与各游戏目录）
```

## 架构

- 各游戏引擎（UMD）与桥接逻辑复用各游戏目录的源文件，本目录只提供**统一 GUI 壳**（`shell.js`）：
  按 SPA 路由自动挂载/卸载对应游戏面板；斗兽棋通过 `canShow`（检测到棋盘）控制显示时机。
- 各游戏目录的独立版 `.user.js` 由 `game-shell.js` 的 `HQ.mountStandalone()` 驱动，两者共用同一套桥接源码。
