# hullqin跳棋 · 跳棋 AI 助手（game.hullqin.cn）

油猴脚本，为 [桌游合集](https://game.hullqin.cn/tq) 的跳棋（中国跳棋，非国际跳棋）提供 💡提示 与 🤖托管。
**支持 2/3/4/5/6 人全部阵营布局**、10/15 棋子两种模式、普通/超级跳规则变体。

## 构建

```bash
node build.js        # 产出 跳棋AI助手.user.js（依赖 ../hullqin-shared）
node tq.test.js      # 引擎测试（33 项：棋盘表/走法/胜负/多人仿真/搜索强度）
```

## 页面逆向结论（tq chunk 模块 4 + UI 层）

- **棋盘**：121 格六边形星形；位置 idx → 轴坐标 (q,r)=U/L[idx]（逆向站表，312 条无向邻接）；像素 `fE = [100*(q+r/2), 100*r*0.866025]`
- **营地**：camp i = 位置 10i..10i+9；15 子制每营另加 5 延伸格（M 表：60-64/64,70,77,85,117/...）
- **目标**：营 c 的目标 = 营 (c+3)%6（对面）；10 子全部进入目标营 = 完胜，按完成先后记 winnerId
- **布局模式**（逆向 f/h 表）：2 人 [0,3]/[0,2]/[0,1]，3 人 [0,2,4]/[0,1,2]，4 人 [0,1,3,4]/[0,1,2,3]/[0,1,2,4]，5 人全营-1，6 人全营；15 子制仅 2/3 人
- **走法**：相邻空格单步；跳过棋子落镜像格（落点=2×子−当前格，子与落点间须全空）；链跳不可重复落点；`route=[起点,落点...]`；rule=1 超级跳（同向距离 2-7 隔空跳）
- **状态**：组件 `props.view`（已展开：waitFor/playerPieces/pos/pieceCount/rule/routeMode/winnerId/finish/lastOp）；waitFor/winnerId **0 基**；我的座位 = `room.position - 1`
- **交互**：棋子 circle（r=45、fill=玩家色）；选中后渲染候选终点圈（r=45、**fill-opacity=0**、stroke 描边），routeMode 0 点终点即走，routeMode 1 逐跳 + 「确认移动」按钮；棋盘另有 121 个 r=35 底格圆点必须排除
- 本地对战（/tq?p）无座位概念：面板可选「代走方」（全部=AI 互走 / 指定玩家）

## 引擎（tq.core.js）

- 走法生成 1:1 复刻站点 z/t2 语义（含链跳 BFS 与超级跳）
- 评估（关键设计，经多轮对局调试收敛）：
  - **尖端距离平方和**：落后子进展收益按平方放大 → 梯次开发，杜绝只推先锋
  - **散布差惩罚**（(max−min)×8）：先锋不脱离大部队 → 防中路堵门死局
  - **入营深度奖励**：尖端优先填营，防止把深格封死；已入营子禁止出营
- 搜索：2 人局 negamax 深度 2~3（候选按「每子最优 + 全局 delta」多样性截断）；多人局走后梯队代价最小 + 噪声
- **防死循环**：根节点按近期局面重复次数递增扣分（avoidKeys，同斗兽棋机制）——残局等值 Plateau 不再横跳
